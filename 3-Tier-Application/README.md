# Three-Tier Goal Tracker

A goal tracking application with a Node.js frontend, Go API, and PostgreSQL database for deployment to an existing Azure Kubernetes Service (AKS) cluster.

See [DEPLOYMENT.md](DEPLOYMENT.md) for prerequisites, Azure access requirements, the PowerShell deployment command, and troubleshooting. The normal deployment reuses existing AKS, ACR, and Key Vault resources; Terraform is an explicit, plan-reviewed option.
